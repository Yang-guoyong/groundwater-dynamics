# groundwater-dynamics（地下水动力学）

“地下水动力学”是水文与水资源工程专业的核心主干课程，主要研究地下水在岩石空隙中的运动规律。课程以水文地质学和水力学为基础，强调从物理概念到数学模型的转化，是连接基础理论与工程应用的重要桥梁。学习本课程应重点关注以下内容：

一、地下水的赋存与运动机理 

地下水的运动受水的物理性质、含水层空隙特征及其力学性质共同控制。空隙既为地下水提供储存空间，也构成流动通道；水头差则是地下水从高能量位置向低能量位置运动的主要驱动力。将空隙的储水和导水能力、水头分布等影响因素定量化，是进行地下水工程计算的基础。达西定律描述了水头梯度与地下水渗流速度之间的线性关系，是层流条件下研究地下水运动的基本定律。

二、数学模型方法

模型化是将实际地下水系统转化为数学表达的有效途径。在满足质量守恒的水均衡方程基础上，结合达西定律，可导出以水头为因变量的地下水运动微分方程。为使方程具有确定解，还需补充初始时刻的水头分布和边界处的质量与能量交换条件，即初始条件与边界条件。这三者共同构成地下水流动的数学模型。对于简单、理想化的模型，可通过解析方法求解；对于水文地质条件较为复杂的模型，则需借助有限差分法、有限元法等数值方法进行求解。

三、地下水向井流动的经典模型及其应用

地下水向井流动模型是水文地质工作中应用最广泛的数学模型之一。其中，Theis模型、Hantush-Jacob模型和Neuman模型分别刻画了承压无限含水层、有越流补给的无限含水层以及潜水含水层中地下水向完整井运动的规律。这些经典模型均具有解析解，可根据观测数据反求渗透系数、储水系数等水文地质参数。尽管实际条件与理论假设存在差异，仍可在此基础上对参数进行评估、修正，并用于地下水位动态预测。此外，叠加原理可将复杂问题拆分为若干简单模型进行线性叠加，是处理群井、边界等特殊水文地质问题的有力工具。

通过本课程的学习，学生应能够初步运用地下水动力学理论分析实际水文地质问题，建立相应的数学模型，求解简单模型，并能应用经典解析解进行定量评价，为今后从事水资源开发、环境保护、地质工程等领域的工作筑牢坚实的理论与技术基础。

本仓库包含讲义、幻灯片（PDF）、实验、作业等，适用于水文与水资源工程、地质工程。
